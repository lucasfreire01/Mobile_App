# SagaNexus

Fonte oficial: `Logotipo SagaNexus Azul e Verde.png`, fornecida pelo usuário.

- `saganexus-original.png`: cópia byte a byte do arquivo original (1774 × 887).
- `saganexus-logo.png`: mesmo desenho, com margens externas reduzidas e fundo quase branco removido. Sem alteração das cores ou da geometria.
- `saganexus-symbol.png`: recorte do símbolo S na região `(180, 245, 560, 650)` da imagem original, centralizado em uma tela transparente de 396 × 396.

Os derivados foram preparados localmente com Pillow; não há dependência de processamento de imagens no aplicativo nem assets externos.
